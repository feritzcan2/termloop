How it works

An MCP tool for agent-to-agent consults.

Every running agent in TermLoop exposes mcp__termloop__ask_to. When an agent calls it, the target agent receives a message in its own loop, answers in its own context, and the response flows back — no copy-paste, no context juggling.

01

Agent A asks

Claude calls ask_to(target: "codex", question: "...") with full context.

02

Agent B answers

Codex receives the prompt in its own session, thinks with its own model and tools, replies.

03

A keeps going

The response returns inline. Claude continues the task with a second opinion already in hand.

// Inside any TermLoop agent
await mcp__termloop__ask_to({
  target: "codex",
  question: "Does this migration look safe under concurrent writes?",
  context: { files: ["db/0042_users.sql"] }
});
Why it matters

Stop being the message bus between your agents.

Most multi-agent setups fall apart because you end up routing context by hand — paste this, summarize that, switch tabs. ask_to turns that into one tool call.

Different models excel at different things. Claude reasons through ambiguity well; Codex hammers compile errors; Gemini is fast on long context. Let them play to type — and let them ask each other instead of you.
