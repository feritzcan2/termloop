# Homebrew Tap for cmux

This is the official Homebrew tap for [cmux](https://github.com/feritzcan2/termloop), a Ghostty-based macOS terminal with vertical tabs for AI coding agents.

## Installation

```bash
brew tap feritzcan2/termloop
brew install --cask termloop
```

## Updating

```bash
brew upgrade --cask termloop
```

## Uninstalling

```bash
brew uninstall --cask cmux
brew untap feritzcan2/termloop
```
