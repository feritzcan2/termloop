yerleşim

Pinned blok .pinned footer'ın hemen üstüne oturur. Üstteki workspace listesi doğal flex ile uzar (.spacer-flex), pinned + footer her zaman dipte kalır — ekran kısa olunca bile.

satır yoğunluğu

Normal .ws satırları iki satırlı (~34px). Quickaction .qa satırları tek satırlı, 18px. Mesaj: "bu bir çalışma alanı değil, geçici bir agent koşusu."

durum dili

Sol 2pt renkli spine tek durum sinyali — yeşil = koşuyor, amber = kullanıcı bekliyor, gri = bitti, kırmızı = hata. Ayrı dot sütunu yok; koşan agent glyph'in çevresinde sessiz halo pulse'u var.

agent glyph

14x14 kare, tek harf: C (Claude), X (codeX), G (Gemini). Durumla tintlenir. Uzun CLAUD/CODEX/GEM rozeti yerine; hem dar sidebar'a sığar hem koşan model kimliği korunur.

etkileşim

Row tıklanınca workspace seçimi olur (mac-blue gradient + beyaz spine). Hover'da × görünür, tek tıkla agent'ı sonlandırır. cursor: grab ile sürükle-bırak'a hazır.

swift tarafı

Uygulamada TermLoopSidebarFooter'ın üstüne yeni bir PinnedQuickActionAgents view'i, AgentRunDisplay / ActiveAgentPinStore'dan besleniyor. QuickActionLRUStore mevcut kayıtları sıralamak için kullanılabilir.

drag-drop pipeline

Mevcut UILayout.md · SideMenuTreeLayout iki-UTI deseni ile uyumlu: pinned satırlar yeni bir com.termloop.quickaction-agent UTI'si ile .onDrag yapar. SidebarTreeDropDelegate bu UTI'yi üçüncü tip olarak tanır; folder'da .into, workspace satırında .above/.below aynen uygulanır.

.into → folder atama

Folder'a bırakıldığında: (1) WorkspaceMetadataStore.setFeatureId, (2) SidebarLayoutStore.reindexParentIfNeeded + append, (3) FolderTreeState.shared.setExpanded(dest, true) auto-expand, (4) positionVersion tick. Aynı didReorderSidebarTab hook hattı.

landed agent satırı

Folder içindeki agent workspace'i normal TabItemView'dan kompakt: sol 2pt yeşil spine, 14x14 tek harf rozeti. Koşmayı bitirince spine grileşir, rozet kaybolur, satır standart .ws'ye "terfi" eder (veya sağ tık → Detach from folder).

indicator stili

.drop-into: 2pt mac-blue iç çerçeve + %8 tint. .drop-above/.below: 2pt mac-blue çizgi satırın üst/alt kenarında. Ghost satır cursor'u izler, -1.2° rotasyon + + into / ↑ above badge.

cross-system UTI

Pinned drag kendi UTI'siyle çıkar; SidebarTabDropDelegate (com.cmux.sidebar-tab-reorder) onu tanımaz → workspace inline drop'a karışmaz. Sadece SidebarTreeDropDelegate eşleşir. .ownProcess visibility UTI harici sızıntıyı engeller.
