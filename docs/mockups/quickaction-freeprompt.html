How it works under the hood QuickActionRunResolver · freePrompt slot

Template-less = LRU carrier + promptOverride

The resolver doesn't actually run "without" a template — AgentRunner needs 11 fields and at least a model. Instead:

1 Carrier template

A hidden LRU slot __free_prompt__ tracks the last-used "carrier" (model + permission + any system prelude the user wants). Defaults to the Default free-prompt template set in settings (sonnet-4.6, acceptEdits).

2 Override slot

The typed text lands in AgentRunRequest.promptOverride, replacing whatever prompt the carrier would have sent. triggerReason becomes "quickAction.freePrompt".

3 Advanced edits stick

Changes from the F3 table (model, permission, mode) write back to the __free_prompt__ LRU entry, so the next shift-shift remembers what you set — without contaminating any real template's memory.

For the user it feels like "just type and send." For AgentRunner it's still a regular request with every required field filled — no code path needs a "templateless" mode.
