Interaction spec · key behaviors for QuickActionView / QuickActionViewModel
Dismissal
  • Esc while pane closed → palette closes
  • Esc while advanced pane open → closes pane only
  • Click outside NSPanel → closes palette
  • Target app change → closes palette
  • ↵ (launch) → inflight 120 ms → fade-out
Launch confirmation
  • Selected row flips to inflight state on submit
  • Fade palette opacity 1 → 0 over 140 ms after run accepted
  • Toast appears top-right: ⌘R reveal, auto-hide 2.4 s
  • No double-launch: Enter disabled during inflight window
Always-visible cues
  • Footer: ↵ run · ⌘↵ advanced · ⌘T target · esc close
  • Target pill shows active workspace/project + shortcut hint
  • Permission chip on row = no hidden bypass
  • Required variables shown on row before advanced opens
  • Scope mismatch (workspace-only on root) row disabled, not hidden
