Signal

Bir worktree CODER tag alır iff git diff HEAD veya staged diff en az 1 kez pozitif olmuş (ever-dirty). Clean worktree'ler sade kalır, "no changes" sub-row'u cortical yük oluşturmaz.

Canlılık

Agent hâlâ yazıyorsa is-live → dotpulse. Agent detach olduysa tag kalır ama nabız durur. Böylece "bu worktree'de iş var" vs "şu an yazılıyor" ayırt edilir.

Diff stat

Sub-row'da +N / −N · N files. Terminal-native monospaced mood, ek chrome yok. Selected state'te beyaz tonlara iniyor.

Epic counter

Epic satırında 3 CODER rollup. Footer'da global sayım. Kullanıcı "bu folderda gerçekten iş yapan kaç branch var" sorusuna 1 bakışta cevap verir.
